# 🚨 社内インシデント報告アプリ

UTO Inc.の社内インシデント管理システム

## 🚀 機能

### 📋 インシデント一覧
- ✅ 優先度別の色分け表示（高:赤、中:黄、低:緑）
- ✅ ステータス別のバッジ表示
- ✅ 検索・フィルター機能（キーワード、ステータス、優先度）
- ✅ 並び替え機能（作成日、更新日、優先度）
- ✅ インライン編集・削除ボタン

### ⚡ 新規報告フォーム
- ✅ 必須項目のバリデーション
- ✅ カテゴリー選択（システム障害、決済問題、メール問題など）
- ✅ 優先度設定（高・中・低）
- ✅ 担当者アサイン機能
- ✅ リッチなフォームUI

### 📊 詳細表示
- ✅ インシデントの詳細情報表示
- ✅ ステータス更新機能
- ✅ コメント・タイムライン機能
- ✅ 経過時間表示

## 🏁 セットアップ

### 前提条件
- Node.js 18以上
- npm または yarn

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/YOUR_USERNAME/incident-reporter.git
cd incident-reporter

# 依存関係をインストール
npm install

# 開発サーバーを起動
npm run dev
```

### ビルド

```bash
# プロダクションビルド
npm run build

# ビルド結果をプレビュー
npm run preview
```

## 📱 使用方法

1. **新規報告**: 右上の「⚡新規報告」をクリック
2. **詳細表示**: インシデントカードをクリック
3. **編集**: ✏️ アイコンをクリック
4. **フィルター**: 検索ボックスや絞り込み機能を使用
